# Vanguarda Kids

Site de aluguel de brinquedos para fim de semana em Formosa do Rio Preto, BA.

[![Ver site no ar](https://img.shields.io/badge/Ver%20site%20no%20ar-00F5FF?style=for-the-badge&labelColor=0D1117)](https://brinquedos-theta.vercel.app) [![Portfólio](https://img.shields.io/badge/Portfólio-FF00E4?style=for-the-badge&labelColor=0D1117)](https://aknoleonel.github.io)

## Sobre o projeto

Site da Vanguarda Kids, que aluga pula-pulas, pistas, videogames e outros brinquedos. O cliente escolhe no celular, recebe em casa e devolve na segunda. Tem até um minijogo da cobrinha para as crianças.

## Destaques

- Catálogo de brinquedos com preço por fim de semana
- Passo a passo do aluguel: escolha, receba, brinque e devolva
- Minijogo da cobrinha jogável no próprio site
- Depoimentos de clientes e pedido pelo WhatsApp

## Tecnologias

React · Vite · Framer Motion · Lucide Icons

## Rodando localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção: `npm run build`.
